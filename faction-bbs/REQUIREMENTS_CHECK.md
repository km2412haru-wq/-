# 要件確認書 — 派閥対抗・時限決戦型BBS MVP

要件を1項目ずつ読み、**解釈が分かれる点・要件同士の矛盾・書かれていない点**を洗い出した。
各項目に「推奨案」を付けたので、問題なければ「Q-xx は推奨でOK」とだけ返してもらえれば計画に反映する。

- 優先度 **A** = 1週目の実装前に必要（データ構造や画面の根幹に影響）
- 優先度 **B** = 2〜3週目までに必要
- 優先度 **C** = 本番前までに決めればよい（設定値・文言など）

確定済み（前回回答）: AI審判が主／異議の代表＝貢献度最上位／L0観客・L1ログイン・L2実績／メール＋パスワード認証

## 1. 要件同士の矛盾・緊張関係（最優先で確認したいもの）

### Q-01 「説得が軸」と「AI審判が主」の関係　【A】
- 原文: 「勝敗は『説得（鞍替え）』を軸に判定する」／回答: 「AI審判が主」
- 論点: AIが主審だと、説得（鞍替え）が勝敗にどれだけ効くかはルーブリック次第になる。極端な場合、鞍替えが多い陣営がAI判定で負ける。
- **推奨案**: ルーブリックの最重視観点を「説得実績（指名された鞍替えの数と、その指名レスの内容）」にし、配点の過半をここに置く。AIには陣営別の説得ポイントと指名レス本文を必ず渡す。
- 別案: 説得ポイント差が大きい（例: 2倍以上）ときはAIを呼ばずに説得ポイントで決める。

### Q-02 「鞍替えでは必ず指名」と「指名つきのみ計上」　【A】
- 原文: 「必ず『説得されたレス』を1つ指名する。指名つきのみ説得ポイントに計上」
- 論点: 指名が必須なら「指名なしの鞍替え」は存在せず、後半の条件が意味を持たない。次のどちらの意図か。
  - (a) 指名必須。後半は「指名レスが後で折りたたまれた／取り消された場合は計上しない」の意味
  - (b) 指名は任意。指名なしでも鞍替え（陣営移動）はできるが、説得ポイントは付かない
- **推奨案**: (a)。指名なしの鞍替えを許すと「説得されていない陣営移動」が混ざり、指標（鞍替え率）の意味が薄れる。

### Q-03 「陣営は固定」と「鞍替え」　【A】
- 論点: 「固定」は「鞍替え以外では変えられない」の意味と解釈したが、次が未定義。
  - 鞍替え後は新陣営として書き込めるか
  - 鞍替え前に書いたレスはどちらの陣営として扱うか
  - 鞍替えで戻る（A→B→A）ことは「1回」の制限で不可、で良いか
- **推奨案**: 鞍替え後は新陣営として書き込み可。過去レスは書いた時点の陣営のまま（表示に「のちに鞍替え」の印）。戻りは不可。

### Q-04 「最終人間投票」とは何か　【A】
- 原文: 「不一致なら『判定保留』で人間投票を優先」「最終人間投票は、鞍替えと二重計上しない」
- 論点: 「最終人間投票」が次のどちらかで、画面・スケジュールが大きく変わる。
  - (a) 期間中の票（観客票＋参戦者の締切時点の所属陣営）を締切で集計したもの
  - (b) 締切後（または3日目）に、別途「どちらが勝ったと思うか」を投票する独立したイベント
- (b) の場合、「鞍替えと二重計上しない」は「鞍替えした人の最終投票は数えない（または鞍替え先に固定する）」等のルールが必要になる。
- **推奨案**: (a)。追加の投票期間が不要で、3日間で完結する。二重計上回避は「鞍替えは所属移動として1票、説得ポイントはAI入力にのみ使う」で担保（計画書 2.5）。

### Q-05 観客票を入れた後にログインして参戦した場合　【A】
- 論点: 同じ人が「端末の観客票(0.2)」と「ログイン参戦の1票(1.0)」で二重に数えられる。
- **推奨案**: ログインして参戦した時点で、その端末の観客票を無効化（取消しイベントを追記）。ログイン中は観客票ボタンを出さない。別端末・ログアウトでの重複は「弱い制限」として許容。

### Q-06 異議の入力項目に「論点」がない　【A】
- 原文: 「異議の理由文そのものは審判AIに渡さない。論点と該当レス番号のみ渡す」／入力は「種類・該当レス番号・理由・期待する変更」
- 論点: AIに渡す「論点」がどの入力項目に当たるかが不明。
- **推奨案**: 「種類（選択式）」を論点とみなし、種類ごとに運営が用意した定型の論点文に変換してAIに渡す。「期待する変更」も自由文なのでAIには渡さない。

### Q-07 「同時開催は1戦のみ」と判定延期・異議期間の重なり　【B】
- 論点: 費用上限で判定が翌日に回り、さらに異議・再審が続くと、次週の開始時刻に前の戦が終わっていない可能性がある。
- **推奨案**: 「同時開催」は「書き込み・投票を受け付けている戦」が1つという意味にする。前の戦の判定・異議処理は次の戦と並行してよい。ただし判定の費用予算は前の戦を優先する。
- 別案: 前の戦が確定するまで次の戦の開始を遅らせる（週の開始日がずれる）。

### Q-08 異議代表「貢献度最上位」と貢献度の定義　【A】
- 論点: 貢献度の算定式が要件にない。また減点は作らない方針のため、通報で折りたたまれた人でも最上位になり得る。鞍替えした人が最上位の場合、どちらの陣営の代表か。
- **推奨案**:
  - 貢献度 = 書き込み1件×1 ＋ 自分のレスが説得指名された回数×5 ＋ 代表レス選出×10（係数は設定ファイル）
  - 鞍替え済みユーザーは代表にならない（陣営の代表として不自然なため）
  - 折りたたまれたレスがある人は代表から除外（減点ではなく資格除外）
  - 同点は早く参戦した人
