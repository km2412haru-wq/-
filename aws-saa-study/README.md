# AWS認定 学習ツール

AWS認定資格対策のための個人学習アプリです。画面上部の「学習する資格」セレクターで資格を切り替えながら、「① 体系的インプット → ② クイズ演習 → ③ 模擬試験」の3段階で学習が進む構成になっています。

現在対応している資格:

- **AWS Certified Solutions Architect – Associate（SAA-C03）**
- **AWS Certified Cloud Practitioner（CLF-C02）**
- **AWS Certified AI Practitioner（AIF-C01）**

React + Vite のシンプルなSPAで、データはすべてブラウザの `localStorage` に保存されます（サーバー不要・個人利用のみを想定）。進捗・クイズ履歴・模擬試験結果は資格ごとに別々に記録されます。

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番ビルド、`npm run preview` でビルド結果を確認できます。

## 3つの学習モード

### ① 体系的インプット（`/study`）
選択中の資格の試験ドメインごとに、主要サービス・トピックの要点整理ページを掲載しています。サービス名の下には正式名称（英語）も併記しています。サイドバー（モバイルでは開閉式メニュー）からドメイン→サービスを選んで読み、「読んだ」チェックボックスで進捗を記録します。

### ② クイズ演習（`/quiz`）
ドメイン別に4択問題を出題します。回答後に正解・不正解の理由を解説表示し、間違えた問題は自動的に復習リストに入り、簡易的な間隔反復（1日後→3日後→7日後）で再出題されます。復習期限が来るとダッシュボードに通知が表示されます。

### ③ 模擬試験（`/exam`）
20問・40分のミニ模擬試験です（本番の問題数・時間は資格ごとに異なりますが、短縮版から始められる構成にしています）。各資格の公式ドメイン出題比率に応じてバランスよく出題し、試験中は解説を表示せず、終了後にまとめて採点してドメイン別正答率と間違えた問題の一覧を表示します。

### 進捗ダッシュボード（`/`）
選択中の資格について、サマリー読了率（ドメイン別）、クイズ正答率（ドメイン別）、模擬試験の受験履歴とスコアを確認できます。

## ホーム画面・デスクトップに追加する（PWA対応）

このアプリはPWA（Progressive Web App）対応になっており、デプロイ先のURLをブラウザで開くと、ホーム画面やデスクトップにアプリのアイコンとして追加できます。

- **スマホ（Chrome/Safari）**: ブラウザメニューの「ホーム画面に追加」
- **PC（Chrome/Edge）**: アドレスバー右側のインストールアイコン、またはメニューの「アプリをインストール」

インストールすると、ブラウザのアドレスバーなしでアプリのように起動します。データは引き続きブラウザの`localStorage`に保存されるため、インストールしなくても機能に違いはありません。

## データ構造

サンプルコンテンツは `src/data/summaries.json`（サービス・トピックの要点整理）と `src/data/questions.json`（クイズ・模擬試験の問題）に外部化されています。各エントリは `exam` フィールド（`"SAA"` / `"CLF"` / `"AIF"`）でどの資格向けかを識別します。現状、各資格・各ドメイン5サービス分のサマリーと5問ずつのサンプル問題を用意しています（SAA・CLFはそれぞれ4ドメイン×5＝20問、AIFは5ドメイン×5＝25問、計65問）。内容はClaudeの知識をもとに作成したサンプルです。料金や制限値など不確かな数値は本文中に「要確認」と明記しています。

資格そのもののメタデータ（ドメイン構成・出題比率・ミニ模試の問題数と時間など）は `src/data/exams.js` にまとまっています。新しい資格を追加する場合は、ここに資格情報を追加したうえで `summaries.json` / `questions.json` にその資格向けのコンテンツを追加してください。

### summaries.json

```json
{
  "exam": "SAA",
  "domain": 1,
  "service": "IAM",
  "fullName": "AWS Identity and Access Management (IAM)",
  "overview": "サービス概要",
  "keyPoints": ["ポイント1", "ポイント2"],
  "examTips": "試験で狙われやすいポイント"
}
```

### questions.json

```json
{
  "id": "q001",
  "exam": "SAA",
  "domain": 1,
  "services": ["IAM", "S3"],
  "question": "問題文",
  "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  "correctIndex": 2,
  "explanation": "正解の理由と、他の選択肢がなぜ違うかの解説"
}
```

## コンテンツを充実させる

参考書やAWS公式資料（PDFなど）が用意できたら、Claude Codeにその内容を踏まえて `summaries.json` と `questions.json` を充実させるよう依頼できます。各ドメインのサービス数・問題数を増やしても、既存のアプリ構造・ロジックはそのまま使えます。

## 技術スタック

- React + Vite
- React Router（ページ遷移）
- React Context（`src/context/ExamContext.jsx` — 選択中の資格をアプリ全体で共有）
- Tailwind CSS（スタイリング）
- localStorage（進捗・クイズ履歴・模擬試験結果の永続化。ストレージキー: `saa-study-data-v2`、選択中の資格: `saa-study-current-exam`）
