# AWS SAA-C03 学習ツール

AWS Certified Solutions Architect – Associate (SAA-C03) 対策のための個人学習アプリです。
「① 体系的インプット → ② クイズ演習 → ③ 模擬試験」の3段階で学習が進む構成になっています。

React + Vite のシンプルなSPAで、データはすべてブラウザの `localStorage` に保存されます（サーバー不要・個人利用のみを想定）。

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番ビルド、`npm run preview` でビルド結果を確認できます。

## 3つの学習モード

### ① 体系的インプット（`/study`）
SAA-C03の4ドメインごとに、主要サービスの要点整理ページを掲載しています。サイドバー（モバイルでは開閉式メニュー）からドメイン→サービスを選んで読み、「読んだ」チェックボックスで進捗を記録します。

### ② クイズ演習（`/quiz`）
ドメイン別に4択問題を出題します。回答後に正解・不正解の理由を解説表示し、間違えた問題は自動的に復習リストに入り、簡易的な間隔反復（1日後→3日後→7日後）で再出題されます。復習期限が来るとダッシュボードに通知が表示されます。

### ③ 模擬試験（`/exam`）
20問・40分のミニ模擬試験です（本番は65問130分ですが、短縮版から始められる構成にしています）。4ドメインから出題比率に応じてバランスよく出題し、試験中は解説を表示せず、終了後にまとめて採点してドメイン別正答率と間違えた問題の一覧を表示します。

### 進捗ダッシュボード（`/`）
サマリー読了率（ドメイン別）、クイズ正答率（ドメイン別）、模擬試験の受験履歴とスコアを確認できます。

## データ構造

サンプルコンテンツは `src/data/summaries.json`（サービスの要点整理）と `src/data/questions.json`（クイズ・模擬試験の問題）に外部化されています。各ドメイン5サービス分のサマリーと5問ずつ、計20問のサンプル問題を用意しています（内容はClaudeの知識をもとに作成したサンプルです。料金や制限値など不確かな数値は本文中に「要確認」と明記しています）。

### summaries.json

```json
{
  "domain": 1,
  "service": "IAM",
  "overview": "サービス概要",
  "keyPoints": ["ポイント1", "ポイント2"],
  "examTips": "試験で狙われやすいポイント"
}
```

### questions.json

```json
{
  "id": "q001",
  "domain": 1,
  "services": ["IAM", "S3"],
  "question": "問題文",
  "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  "correctIndex": 2,
  "explanation": "正解の理由と、他の選択肢がなぜ違うかの解説"
}
```

## コンテンツを充実させる

参考書やAWS公式資料（PDFなど）が用意できたら、Claude Codeにその内容を踏まえて `summaries.json` と `questions.json` を充実させるよう依頼できます。各ドメインのサービス数・問題数を増やしても、既存のアプリ構造・ロジックはそのまま使えます。

## 技術スタック

- React + Vite
- React Router（ページ遷移）
- Tailwind CSS（スタイリング）
- localStorage（進捗・クイズ履歴・模擬試験結果の永続化）
