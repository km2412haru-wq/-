# AWS資格 模擬試験アプリ

AWS認定資格（CLF-C02 / SAA-C03）対策の、10分間で完結するミニ模擬試験アプリです。資格と難易度レベルを選んで受験すると、結果画面で予想本番スコアが確認できます。

`aws-saa-study`（体系的インプット＋クイズ＋模擬試験の学習アプリ）とは別の、独立したアプリです。コード・依存パッケージは共有していません。

React + Vite のシンプルなSPAで、データはすべてブラウザ内で完結します（サーバー不要）。

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番ビルド、`npm run preview` でビルド結果を確認できます。

## 使い方

1. **資格を選択**: CLF-C02（クラウドプラクティショナー）／ SAA-C03（ソリューションアーキテクト – アソシエイト）
2. **難易度レベルを選択**: 基礎 ／ 応用 ／ 高難易度（選んだレベルの問題のみが出題され、他レベルとは混ざりません）
3. **10分間のタイマー**が開始し、1問ずつ4択で回答（選択時点では正誤を表示しません）
4. 全問回答し終えると自動的に結果画面へ。タイムアップした場合は未回答分を不正解扱いとして締め切ります
5. 結果画面でスコア・予想本番スコア・ドメイン別内訳・問題ごとの振り返りを確認

## 出題数

- CLF-C02: 基本7問（本番65問90分の1問あたりの持ち時間から逆算）
- SAA-C03: 基本5問（本番65問130分の1問あたりの持ち時間から逆算）

選んだ資格×難易度の組み合わせで該当する問題数がこの基本数に満たない場合は、その場で実際に存在する問題数まで自動的に出題数を減らし、画面上に案内を表示します（他レベルの問題で埋めたり、同じ問題を繰り返し出題したりはしません）。

## 予想本番スコアについて

正答率から「100 + (正答数/出題数) × 900」という単純な線形換算で100〜1000点の目安を算出します。結果画面には以下を明記しています。

- 本番はIRT（項目応答理論）による重み付け採点であり、この単純換算とは仕組みが異なること
- 今回は1つの難易度レベルの問題のみで受験しているため、複数の難易度が混在する本番の点数とは乖離しうること
- あくまで参考値であり、実際のスコアを保証するものではないこと

合格ラインの目安（CLF-C02: 700点 / SAA-C03: 720点、2026年8月時点のAWS公式情報）と比較した達成状況も表示します。基準は変更される可能性があるため、最新の値は[AWS公式サイト](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html)でご確認ください。

## データ構造

問題データは `aws-saa-study/src/data/questions.json` の40問（CLF20問・SAA20問）をコピーし、以下の基準で1問ずつ`difficulty`フィールド（`basic` / `applied` / `hard`）を追加したものです。

- **basic（基礎）**: 単一のAWSサービスや概念の理解を問う
- **applied（応用）**: 2つ程度の判断軸を組み合わせて解かせる
- **hard（高難易度）**: 選択肢同士が紛らわしく、慎重な識別を要求する

```json
{
  "id": "q101",
  "exam": "SAA",
  "domain": 1,
  "difficulty": "basic",
  "services": ["IAM"],
  "question": "問題文",
  "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  "correctIndex": 1,
  "explanation": "正解の理由と、他の選択肢がなぜ違うかの解説"
}
```

資格そのもののメタデータ（ドメイン構成・出題基本数・合格ラインなど）は `src/data/exams.js` にまとまっています。

## 今回のスコープ外

- ドメインごとのセクション分け・時間配分
- 正答率に応じたアダプティブな難易度変化（レベルは開始前に固定選択する方式のみ）
- 出題履歴を踏まえた「直近に出た問題を避ける」ロジック
- 途中保存・再開機能
- 見直し用フラグ機能
- 受験履歴の永続化（結果はページを離れると失われます）

## 技術スタック

- React + Vite
- Tailwind CSS（スタイリング）
- サーバー・データベースなし（全問題データはビルド時にバンドルされる静的JSON）

## デプロイ（Vercel）

このリポジトリはモノレポで、`ai-ma-radar/` `world-history-map/` `aws-saa-study/` と同様に、**同じGitHubリポジトリから複数のVercelプロジェクトを作る**構成に揃えています。

1. Vercelで「Add New... → Project」→ このリポジトリをImport（既にImport済みなら新規Import不要）
2. **Root Directory** を `aws-exam-mock` に設定（Vite製アプリなので、Framework Presetは自動的に「Vite」として検出されます）
3. Deploy

詳しくはリポジトリルートの `README.md` を参照してください。
