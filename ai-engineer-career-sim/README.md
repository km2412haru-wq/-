# 駆け出しAIエンジニア物語

22歳・新卒でシード期スタートアップに飛び込むところから始まる、**AIコンサルタントのキャリアを疑似体験するシミュレーション風インタラクティブWebアプリ**です。限られた「開発工数（AP）」「予算」「残り納期」をやりくりしながらAI導入プロジェクトを進め、実績を積むと外資・日系問わず様々な企業からスカウトが届くようになります。

## できること

- **ターン制のキャリアシム**：1ターン=2ヶ月。2ヶ月ごとにAP（行動回数）を消費してアクションを選択。予算・進捗・精度・満足度・疲労度・トラブル発生率をゲージで可視化し、`recharts` で推移をグラフ表示。プレイヤーは22歳・AIコンサルタントとしてスタートし、月日の経過とともに年齢を重ねていく。年齢を重ねるたびに評価スコアに応じた昇給があり、年収は在職中も少しずつ変動する
- **4フェーズ制のプロジェクト進行**：実際のAIエンジニアの業務工程になぞらえ、プロジェクトは「データ収集・分析→AIモデル開発→システムへの実装→運用・改善」の4フェーズを順に進む。進捗が伸びるほど自動でフェーズが進み、フェーズごとに使えるアクションが入れ替わる（例：データ収集・分析フェーズは要件定義/データ収集、システムへの実装フェーズはWeb API化/オンプレ/クラウド推論/エッジ実装から選ぶ「システムへの実装方式を選ぶ」など）。ミスで進捗が下がるとフェーズが後戻りすることもある
- **案件（ミッション）システム**：プロジェクトごとに「ECサイトのレコメンドエンジン刷新」「AI導入ロードマップ策定支援」「広告クリエイティブ自動生成AI」など18種類の依頼内容・成功条件・ボーナス条件を持つ案件がランダムに割り当てられる。案件ごとに「AI開発エンジニア」「AIコンサルタント」「MLOpsエンジニア」「データサイエンティスト」「広告テックエンジニア」といった職種フレーバーが異なり、今の勤務先の企業文化（スタートアップ/外資/日系大手/日系中堅）に応じた傾向で選ばれる。転職すると出やすい案件・職種のラインナップも変わる
- **ミッション適性システム**：各案件には「刺さるアクション」が2つ設定されており、それを選ぶと評価スコアの伸びが倍になる。案件ごとに何を優先すべきかが変わるため、「同じボタンを押せば常に正解」にならない
- **業務アクション**：要件定義、データ収集・前処理（質 vs 量、データ収集・分析フェーズ）、モデル選定（自社学習/API利用/OSSファインチューニング）・プロトタイプ作成・プロンプトエンジニアリング/RAG構築（AIモデル開発フェーズ）、システムへの実装方式を選ぶ・コードレビュー（システムへの実装フェーズ）、運用しながら改善する・評価・テスト（運用・改善フェーズ）に加え、フェーズを問わず使える技術記事講読・資格勉強・チーム相談・休息の全13種。さらに案件の職種（AI開発エンジニア/AIコンサルタント/広告テックエンジニア/MLOpsエンジニア/データサイエンティスト）専用の5アクション（例：コンサル案件だけの「経営層向け提案資料を作る」）が案件に応じて出現し、常に同じボタンが最適解にならないようにしている。用語解説ツールチップに加え、各アクションが「いつ使うか」「何にどう効くか（評価スコアへの影響を含む）」を明記
- **資格勉強システム**：「資格勉強をする」アクションでG検定・基本情報技術者試験・TOEIC・統計検定・中小企業診断士・PMPをコツコツ勉強できる。お金で即取得するのではなく、複数回の勉強で習熟度が100%に達すると正式に取得。取得すれば技術力/コミュ力が恒久的に底上げされる
- **勤務地・住まいシステム**：勤務地は会社の業界によって自動的に決まり（製造業は郊外の工場地帯になりやすい）、シェアハウス→ワンルームアパート→デザイナーズマンション→マイホームと住まいのグレードを上げていける。住まいが良いほど家賃は上がるがモチベーションが上がり、通勤の負担（疲労）も減る。郊外勤務でも車があれば通勤は楽になる、というように「勤務地」「住まい」「車」が絡み合って通勤の感覚がわかるようになっている
- **個人貯金とプライベート**：会社のプロジェクト予算とは別に、給料から生活費・家賃を差し引いた分が個人の貯金として積み上がる。貯金は「☕ちょっと贅沢する」から「🚗車を買う」まで6種類の買い物カタログに使えてモチベーションが上がり、モチベーションが高いと疲労回復が早くなったり評価スコアが少し伸びたりする。年齢と貯金額に応じてマイホーム購入・結婚・出産といった人生の節目イベントも発生し、合コン・マッチングアプリで交際相手ができると結婚イベントも起きやすくなる。ペットを飼う、ジムに入会する、財布を落とすといった細かいプライベートイベントも起きる
- **ランダムイベント**：APIコスト爆発、ハルシネーション、競合の先行リリース、急な要件変更、サーバーダウンなど「AIエンジニアあるある」に加え、外資特有の英語ミーティング・PIP、日系大手特有の稟議・根回しイベント、合コン・マッチングアプリといった出会いイベント、超低確率のレアイベント（バズ・買収オファー）も収録
- **転職・スカウトシステム**：外資・総合商社・シンクタンク・戦略コンサルなどを大幅に増強した実在の企業から着想を得た100社超を難易度1〜5でリスト化。評価スコアに応じてスカウトが届くほか、自分から難関企業に応募することも可能。選考はクイズではなく、育てた技術力・コミュ力・評価スコアという「実力」の数値で合否が決まる。技術力・コミュ力は上限300まで伸ばせるが、難易度が上がるほど要求される実力は急激に上がり、GoogleやMcKinsey、三菱商事のような最難関(難易度5)企業は何年もかけて実力を積み上げてようやく手が届く「憧れの存在」になっている。さらに企業は一律の難易度では測れないという発想から、今の勤め先との業界の近さ（親和性）が合否に加味される（同業界は大きく有利、隣接業界はやや有利、畑違いはやや不利）。選考プロセスの中身も企業ごとに変化し、戦略コンサルは「ケース面接」、シンクタンクは「論理思考テスト・小論文」、トヨタは「事業理解・プレゼンテーション」、総合商社は「筆記試験」、メーカーは「工場見学」、金融機関は「適性検査」中心など、業界ごとに雰囲気が違う
- **感覚でわかるプロジェクトの調子**：現在の進捗・精度が納期に対するペースと比べてどうかを「☀️順調」〜「⛈️暴風雨」の天気にたとえて常時表示。予算・疲労度・トラブル発生率にも「😌まだ余裕がある」のような一言ラベルが付き、数字を比較しなくても状況が直感的にわかる。連続成功でコンボボーナスが乗っているときは🔥バッジで表示
- **オファー比較**：給与・裁量権・成長環境・安定性・WLB・技術力向上・知名度をレーダーチャートで現職と比較
- **キャリアの分岐**：転職すると馴染み度が下がり、外資→日系大手→中堅企業と文化ごとに異なるイベントセットに切り替わる。引き止めイベントも発生
- **称号・実績・図鑑**：累計評価スコアで称号がランクアップ、隠し要素を含む実績30種以上、企業・イベントの図鑑コレクション、プレイヤーレベル/XP、ローカルランキング、NG+（周回要素）、チャレンジモード（予算半分縛り/2ヶ月クリア縛り）

## 技術スタック

- Next.js 16 (App Router) + TypeScript
- [`recharts`](https://recharts.org/) でスコア推移グラフ・オファー比較レーダーチャートを描画
- 状態管理は `useReducer` 相当の自前リデューサー（`lib/engine/engine.ts`）。外部APIキー・DB不要、進行状況とランキングは `localStorage` にのみ保存

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` で確認できます。

## ビルド

```bash
npm run build
npm start
```
