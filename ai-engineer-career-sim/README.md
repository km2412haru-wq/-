# 駆け出しAIエンジニア物語

シード期スタートアップから始まる、**AIエンジニアのキャリアを疑似体験するシミュレーション風インタラクティブWebアプリ**です。限られた「開発工数（AP）」「予算」「残り納期」をやりくりしながらAIプロダクトを開発し、実績を積むと外資・日系問わず様々な企業からスカウトが届くようになります。

## できること

- **ターン制のキャリアシム**：週ごとにAP（行動回数）を消費してアクションを選択。予算・進捗・精度・満足度・疲労度・トラブル発生率をゲージで可視化し、`recharts` で推移をグラフ表示
- **案件（ミッション）システム**：プロジェクトごとに「ECサイトのレコメンドエンジン刷新」「医療画像診断支援AI」など毎回違う依頼内容・成功条件・ボーナス条件を持つ案件がランダムに割り当てられる。同じ作業ループでも案件ごとに目標や有利な立ち回りが変わるため、単調になりにくい
- **業務アクション**：要件定義、データ収集・前処理（質 vs 量）、モデル選定（自社学習/API利用/OSSファインチューニング）、プロトタイプ作成、プロンプトエンジニアリング/RAG構築、評価・テスト、コードレビュー、技術記事講読、チーム相談、休息の10種。用語解説ツールチップに加え、各アクションが「いつ使うか」「何にどう効くか（評価スコアへの影響を含む）」を明記
- **ランダムイベント**：APIコスト爆発、ハルシネーション、競合の先行リリース、急な要件変更、サーバーダウンなど「AIエンジニアあるある」に加え、外資特有の英語ミーティング・PIP、日系大手特有の稟議・根回しイベント、超低確率のレアイベント（バズ・買収オファー）も収録
- **転職・スカウトシステム**：実在の企業から着想を得た82社を難易度1〜5でリスト化。評価スコアに応じてスカウトが届くほか、自分から難関企業に応募することも可能。選考はクイズではなく、育てた技術力・コミュ力・評価スコアという「実力」の数値で合否が決まる
- **オファー比較**：給与・裁量権・成長環境・安定性・WLB・技術力向上・知名度をレーダーチャートで現職と比較
- **キャリアの分岐**：転職すると馴染み度が下がり、外資→日系大手→中堅企業と文化ごとに異なるイベントセットに切り替わる。引き止めイベントも発生
- **称号・実績・図鑑**：累計評価スコアで称号がランクアップ、隠し要素を含む実績30種以上、企業・イベントの図鑑コレクション、プレイヤーレベル/XP、ローカルランキング、NG+（周回要素）、チャレンジモード（予算半分縛り/1週間クリア縛り）

## 技術スタック

- Next.js 16 (App Router) + TypeScript
- [`recharts`](https://recharts.org/) でスコア推移グラフ・オファー比較レーダーチャートを描画
- 状態管理は `useReducer` 相当の自前リデューサー（`lib/engine/engine.ts`）。外部APIキー・DB不要、進行状況とランキングは `localStorage` にのみ保存

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` で確認できます。

## ビルド

```bash
npm run build
npm start
```

## 免責

登場する企業名は実在の企業から着想を得ていますが、難易度・選考プロセス・演出はすべてゲーム的な脚色であり、各社の実際の採用基準・選考フロー・内部情報を正確に再現するものではありません（タイトル画面フッターにも記載しています）。
