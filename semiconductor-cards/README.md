# 🔬 半導体トレカ図鑑

半導体業界の主要企業30社（TSMC・NVIDIA・Samsungなどの世界大手 ＋ 東京エレクトロン・ルネサス・キオクシアなど日本企業）を、**トレーディングカードをめくる感覚**で見比べながら、ビジネスモデルや競合関係を直感的につかめるWebアプリです。

## できること

- 企業ごとに1枚のカードが並ぶギャラリー表示。カードをタップ／クリックすると裏返り、売上高・営業利益率の目安やビジネスモデルの説明、強み、主な競合が見られる
- カード裏面の「競合」チップを押すと、そのライバル企業のカードまで自動スクロールしてジャンプ（フィルターがかかっていても解除して必ず表示）
- 企業を **EDA／IPコア／ファブレス／IDM／メモリ／ファウンドリ／製造装置／材料** の8つの事業タイプ、**海外／日本** の地域、キーワード検索で絞り込み
- 売上高・利益率・五十音順での並び替え
- カードに⚔️アイコンで「対戦カード」として2枚選ぶと、売上規模・利益率・レア度から計算した「総合力スコア」でカードバトルできる比較モーダルが開く（あくまで遊び用の指標という位置づけ）
- 売上規模に応じてカードに UR / SSR / SR / R のレア度を自動付与し、トレカらしい演出に
- PWA対応でスマホのホーム画面にアイコンとして追加可能

## 技術スタック

- Next.js 16 (App Router) + TypeScript、React 19
- 外部API・DB不要。企業データは `lib/companies.ts` に手作りの静的データセットとして保持（各社IR資料等をもとにした規模感の目安であり、正確な最新値は各社の公式発表を参照）
- ロジックはすべて `lib/` 配下の純粋関数として実装しテスト可能に：
  - `lib/rarity.ts` — 売上規模からレア度を決定
  - `lib/battle.ts` — カードバトルの総合力スコア計算
  - `lib/filter.ts` — 絞り込み・並び替え
  - `lib/cardCode.ts` — カード前面の表示用ロゴ略称の生成
- スタイルはCSS変数によるライト/ダークテーマ対応のプレーンCSS（`app/globals.css`）。3D flipはCSSの `transform-style: preserve-3d` のみで実装し、追加ライブラリなし

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` で確認できます。

## テスト

```bash
npm test
```

レア度判定の境界値、カードバトルのスコア計算と勝敗判定、絞り込み・並び替えロジック、カードコード生成に加えて、企業データセット自体の整合性（id重複がないか、競合として挙げているidが実在するか、数値が妥当な範囲かなど）を検証しています（外部ネットワーク不要）。

## ビルド

```bash
npm run build
npm start
```

## アイコンを再生成する

`public/icons/` はビルド前に生成済みのファイルとしてリポジトリに含まれています。デザインを変えたい場合は `app/icon.tsx` / `app/apple-icon.tsx` / `scripts/gen-icons.mjs` を編集し、以下を実行してください。

```bash
npm run gen-icons
```

## データについて・既知の制限

- 掲載している売上高・営業利益率などの数値は、規模感をつかむための目安です。年度・為替レート・会計基準の違いで実際の数値とはズレがあります。正確な最新情報は各社のIR資料を参照してください。
- 「レア度」「総合力スコア」はゲーム的な演出のために売上規模・利益率から機械的に計算したものであり、企業としての優劣や投資判断を示すものではありません。
- 企業の選定・競合関係・強みの記述はあくまで一般的な理解を助けるための簡略化です。実際のビジネスはもっと複雑で、事業年度によっても状況が変わります。
