# Repository structure

This repository is a monorepo containing four fully independent apps, each with its own `package.json`, dependencies, and Vercel deployment:

- `ai-ma-radar/` — AI M&A Radar (news dashboard, Next.js)
- `world-history-map/` — World History Map (Next.js)
- `aws-saa-study/` — AWS SAA-C03/CLF-C02 study tool (React + Vite SPA, data persisted to localStorage, no server)
- `aws-exam-mock/` — AWS certification mock exam app (React + Vite SPA, no persistence, no server)

There is no shared code between them and no root-level `package.json`. Run `npm install`, `npm run dev`, `npm test`, etc. **inside the relevant subdirectory**, not at the repo root. See the root `README.md` for the full picture, and each subdirectory's own `README.md`/`AGENTS.md` (the latter auto-generated by `next dev` when run inside that subdirectory) for app-specific guidance.
